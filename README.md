# NGS-Data-Analysis
Next Generation sequencing for the  Genetic Diagnosis of Intellectual Disability and Developmental Delay in a Consanguineous Family
Whole-exome sequencing (WES) produces a large number of variants that require systematic filtering and interpretation to identify plausible disease-associated candidates. An annotated WES dataset containing 386,518 variants was filtered by functional region, predicted consequence, population frequency, genotype/inheritance, and variant-call quality. Surviving variants were evaluated using computational prediction scores, ClinVar annotations, gene–disease evidence, and phenotype concordance. The analysis reduced the dataset to 71 working variants, of which 54 were PASS calls. Four genes were prioritized: YY1AP1, PUS10, DOCK11, and SLC6A6 out of which, YY1AP1 was the strongest overall clinical candidate; PUS10 carried the strongest research-level splice candidate; DOCK11 had strong variant-level evidence but weaker phenotype concordance; and SLC6A6 primarily matched the retinal phenotype. In conclusion, no definitive causal variant could be established from the supplied data alone.
